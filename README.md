# Estructuras No Lineales

Implementaciones y ejercicios de estructuras de datos no lineales en  C++

## Contenido

Las estructuras no lineales son aquellas en las que los elementos no siguen una secuencia única, sino que pueden tener múltiples relaciones entre sí. Este repositorio incluye:

- **Árboles**
  - Árbol binario
  - Árbol binario de búsqueda (BST)
  - [AVL / Heap / Trie / otros]
- **Grafos**
  - Representación con lista y matriz de adyacencia
  - Recorridos BFS y DFS
  - [Dijkstra / Kruskal / Prim / otros]
- **[Tablas hash / Conjuntos / Mapas, si aplica]**
